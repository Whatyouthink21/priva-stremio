Desktop vs Stremio Web

Stremio Desktop plays HLS, MP4, and MKV natively over local 127.0.0.1:7000. Stremio Web requires an HTTPS origin (or a Cloudflare tunnel) and cannot decode all MKV tracks in-browser — toggle MKV off on /configure when needed.

Fast partial answers + cache fill

Slow sources never hold fast sources hostage. Once fast providers return streams plus a 1 second grace window, Stremio receives playable links immediately while stragglers finish in the background.

Stateless URL configuration

Every preference lives inside your /<config>/manifest.json install link as base64url JSON — nothing is stored in a database or shared with other users.
