In Stremio: Add-ons → “+ Add Addon” → paste the URL → Install. Then open any movie or series and pick the TG HUB stream.
How playback works. Stremio's built-in player only accepts direct video files (mp4 / m3u8 / mpd), not web pages — so the TG HUB embed cannot play inside it. This addon returns the SDK's externalUrl field instead, which tells Stremio to hand the title off to your browser. You get TG HUB's full player: server switching, quality, multi-audio, subtitles, skip intro/outro and resume.
